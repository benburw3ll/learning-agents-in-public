# Week 10: Jujutsu, stacked PRs, open source

Track: GitHub deep end

## Goal

Use Jujutsu (jj) daily on a real repo for two weeks. Land a stack of three PRs in order. Get one PR merged upstream in an open-source project I use, such as an MCP server, a plugin, or a tool.

## Why it matters

jj has no staging area and conflict-free rebasing, which fits agent workflows unusually well. Open-source contribution teaches review etiquette, CI, and maintainer expectations that transfer anywhere.

## Deliverable

Notes on how jj changed the way I work with agents, a landed 3-PR stack, and a merged upstream PR.

## Done when

- [ ] jj used daily for two weeks, with notes on what changed
- [ ] A stack of three PRs landed in order
- [ ] One upstream PR merged, or reviewed and iterated with the maintainer
- [ ] A comparison of agent behavior in a jj repo versus a git repo

## Stretch

- A jj-aware hook or skill
- Teach an agent to split one big change into a clean stack
