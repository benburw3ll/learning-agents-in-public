# Week 11: Build your own X

Track: Build

## Goal

Pick one classic: a CHIP-8 or NES emulator, a Redis clone, a tiny git, a Lisp interpreter, a ray tracer, or a CodeCrafters track. Drive it with agents while learning the system myself.

## Why it matters

These projects stress long-horizon agent work in a way web apps don't, and they teach how computers actually work. The point is to learn the thing, not to have an agent produce it.

## Deliverable

A working implementation, tests I wrote myself, and a write-up of where the agent struggled.

## Done when

- [ ] The thing runs
- [ ] Tests exist that I wrote, not the agent
- [ ] A write-up of where the agent struggled and what I changed in how I drove it
- [ ] I can explain the core mechanism without looking at the code

## Stretch

- A second implementation in a language I don't know
- Benchmark it against a real implementation
