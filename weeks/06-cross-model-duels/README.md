# Week 06: Cross-model duels

Track: Measure

## Goal

Give the same spec to Claude Code and Codex in separate worktrees, diff the results, have each review the other's pull request, and keep a scoreboard across ten tasks.

## Why it matters

Blog posts tell you which model is better at what. My own data tells me which one is better at my work, and cross-review is a cheap quality gate I can keep using.

## Deliverable

A scoreboard with my own rubric and a write-up of when I reach for which tool.

## Done when

- [ ] Ten tasks run through both tools with identical specs
- [ ] A rubric written before the runs, not after
- [ ] Each tool reviews the other's PR on every task
- [ ] A write-up on strengths, weaknesses, and where review caught real bugs
- [ ] A note on what the cross-review workflow costs in time and tokens

## Stretch

- Add a third contestant at low effort or on a cheaper model and see what I actually lose
- Try "one plans, the other implements, the first reviews" as a pipeline
