# Week 12: Capstone, a personal assistant on the Agent SDK

Track: Build

## Goal

One always-on bot (Discord or Telegram) built on the Claude Agent SDK, using my own MCP servers, with memory and scheduled runs, driven from my phone. It unifies the smaller tools built in earlier weeks.

## Why it matters

Everything before this was a piece. This is the piece that runs every day and has to survive contact with real life.

## Deliverable

A bot running 24/7 on a homelab box or small server, with guardrails from week 04 applied.

## Done when

- [ ] The bot runs continuously somewhere I don't have to babysit
- [ ] It uses at least two of my MCP servers
- [ ] A scheduled run reports something useful daily
- [ ] Guardrails from week 04 are applied and tested
- [ ] Telemetry from week 07 covers it

## Stretch

- Voice input
- Compare with Codex's voice mode for the same tasks
